# AYU-INTEL  
### Explainable AI for AYUSH Public Health Intelligence

---

## Overview

AYU-INTEL is an Explainable AI-based Public Health Intelligence and Personalized AYUSH Decision Support System designed to enhance the Ayush Hospital Management Information System (AHMIS).

The system focuses on:

- Voice-enabled EHR capture
- Outbreak detection using Isolation Forest
- Risk scoring using XGBoost
- SHAP-based explainability
- KNN-based personalized treatment recommendation

---

## Model Architecture

Primary Model Included in This Repository:

- **XGBoost Risk Model**  
  Used for outbreak probability estimation.

Additional planned models:

- Whisper (Speech-to-Text)
- spaCy NER (Entity Extraction)
- Isolation Forest (Anomaly Detection)
- SHAP (Explainability)
- KNN (Similarity Matching)
